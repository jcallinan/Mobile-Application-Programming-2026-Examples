# Week 8: User Feedback and Testing

This folder contains two standalone React examples:

1. **project-1-user-feedback-react** – How to collect and persist user feedback with local state and `localStorage`.
2. **project-2-react-testing-examples** – How to write common React tests, including unit, integration, mocking, snapshot, and basic end-to-end tests.

Each project has its own `package.json` and README with run instructions.
